# Clinical Report Hub

林彥廷醫師（消化內科）診間用的結構化報告工具。單一 HTML 檔，點選片語即產生英文報告，複製後貼進 HIS。

網址：https://adigu2025.github.io/report/

## 收錄工具

| # | 工具 | 用途 |
|---|---|---|
| 01 | Abdominal Ultrasound | 腹部超音波結構化報告 |
| 02 | Thyroid Ultrasound | 甲狀腺超音波，含 ACR TI-RADS 計分 |
| 03 | Carotid Ultrasound | 頸動脈超音波 IMT 與斑塊 |

| 07 | 診斷書結構化 | 診斷與醫囑 |

## 病人資料怎麼處理

全部在瀏覽器內完成，沒有任何後端，程式碼裡沒有 `fetch` 也沒有 `XMLHttpRequest`。病人姓名與病歷號不會離開這台電腦。

未完成的報告會暫存在瀏覽器的 localStorage，只存 12 小時。重新開啟時會「詢問」是否還原，不會自動帶入。按「下一位病人」會立刻刪掉暫存。

## 版面與快捷鍵（2026-10 改版）

- 頂端列直接列出七個工具，分成超音波、內視鏡、文書三組，不用再開下拉選單。
- 螢幕寬度 1280px 以上，報告固定在右側，邊點片語邊看報告；較窄的螢幕維持上下排列。
- 報告框可以直接改字。手動改過之後，再點片語不會覆蓋，報告上方會出現提示；按「改回片語版本」或左側「重新產生報告」才會依片語重寫。
- `Alt`＋`1`～`7` 切換工具；`Ctrl`（Mac 用 `⌘`）＋`Enter` 複製目前的報告。
- 配色改用診所品牌色：Navy `#152831`、Teal `#3E6A7C`、Gold `#BC7F30`。

## 使用注意

- 換病人一律按左下角的「✕ 下一位病人」（診斷書也是），這會清掉病人欄位、所有片語選擇與暫存草稿。
- 片語標籤可以用 Tab 移動、Enter 或空白鍵選取，內視鏡操作中可單手用鍵盤。
- 報告框的「列印」只印報告本文，不印操作介面。
- 第一次連上網開啟後會快取到本機，之後診所網路斷線仍可使用。

## 改版

`index.html` 裡的 `APP_REVISION` 是最後改版日期，顯示在首頁左下角。**每次改版請同時更新兩個地方**：

1. `index.html` 的 `APP_REVISION`
2. `sw.js` 的 `CACHE` 版本字串（沿用同一個日期）

改版後舊的暫存草稿會自動失效，不會被還原到新版介面上。
